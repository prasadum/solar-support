Site admin

Add, edit, reorder and delete lessons, slides, PDFs and Google Form links. Changes go live about 1 minute after you publish. ← Back to the site

Sign in with your GitHub access token to start.

1. Sign in

How to get an access token (one time, 3 minutes)
  1. On GitHub, click your photo (top right), then Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Token name: site admin. Expiration: pick a date (for example 1 year).
  3. Repository access: Only select repositories, then choose this site's repository.
  4. Permissions → Repository permissions → Contents: Read and write. Leave everything else as is.
  5. Click Generate token, copy it, and paste it above. GitHub shows it only once.

Keep the token private; anyone who has it can change this site. Tick “Remember” only on your own computer or phone. To revoke it, delete the token on the same GitHub page.

2. Add an item

PowerPoint files open in Microsoft's free online viewer on the site, so the website must be public. For Google Slides, use File → Share → Publish to web → Embed and paste the link from src="…".

3. Arrange the site

Use ↑ ↓ to change teaching order. Modules set as “Link buttons” show compact buttons, as used for the MCQ question banks. Nothing changes on the live site until you click Publish changes.

4. Files not used on the site

Files in the repository that no item points to. Delete them to keep the site tidy.
